## 1.7.0

**Новое**
- Поиск по всем триггерам сразу. Ctrl+F в коде открывает окно с результатами по триггерам и предпросмотром, Enter переходит к строке
- Замена сразу во всех триггерах
- В поиске есть регулярные выражения, учёт регистра и поиск целого слова, а F3 ходит по совпадениям прямо в коде
- Тёмная тема в редакторе кода
- Локальный тест запускается быстрее, меню игры больше не тормозит вход
- Новые пресеты и тексты GUI из YDWE PK 1.8.4

**Исправлено**
- Карты в формате lni снова открываются с ландшафтом и триггерами
- Локальный тест снова работает в обоих режимах
- Окна локального теста больше не попадают в загрузку игры и не падают при одновременном входе
- В сохранённых кампаниях больше не теряется название и не ломаются карты
- KFMO при тесте больше не удаляет неиспользуемые объекты
- Объекты, созданные через slk с дробными значениями, при каждом сохранении считались изменёнными и перезаписывались
- Если убрать из карты код, который создаёт объекты через slk, эти объекты теперь удаляются при сохранении, даже без require 'slk'

## 1.6.0

**Новое**
- Файлы и папки можно перетаскивать в менеджер импорта прямо из проводника
- Папки импортируются целиком вместе с подпапками, пути внутри карты сохраняют структуру
- Кнопка «Импорт файлов…» позволяет выбрать сразу несколько файлов
- После обновления показывается список изменений, открыть его снова можно в меню KFWE
- В окне обновления видно, что изменилось в новой версии
- Сняты ограничения рельефа, можно делать любой уклон и высоту от -1920 до 1920
- Переделано окно ручного ввода ID нового объекта. ID проверяется сразу при вводе, есть кнопки «Предложенный» и «Дальше по серии», Esc ставит ID по умолчанию

**Исправлено**
- Объект, скопированный с ручным вводом ID, мог получиться без скопированных полей
- После окна ввода ID в редакторе ломались шрифты и масштаб
- Игровые константы больше не сыпят ошибками «Отсутствует строка» и полностью переведены
- В константах «Баланс: может отменить» видно, какую именно способность
- Ошибка «Отсутствует строка: WESTRING_AEVAL_YTIP»
- Название приказа Феникса у Чародея Крови
